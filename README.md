# forex-ai

## 🪙 Gold Day Trade Assistant (XAU/USD) - ระบบสไนเปอร์ 1M สำหรับ IQ Option Forex (CFD)

โปรแกรม AI ช่วยวิเคราะห์กราฟทองคำรายวันสำหรับสาย **1-Minute (1M) Sniper Day Trade & Scalping** จบในวัน ไม่ถือข้ามคืน 
วิเคราะห์ตลาดสดช่วง **19:00 - 22:00 น.** (New York / London Overlap) ผสานระบบ 2-Step Trailing Stop และ Trade Quality Filter (TQF) พร้อมแจ้งเตือนเสียงและเด้งเตือนผ่านหน้าเว็บ

---

## ✨ จุดเด่นของโปรแกรม

1. **โฟกัสทองคำ (XAU/USD)**:
   - ดึงข้อมูลกราฟสดแบบ Real-time พร้อมคำนวณกรอบราคาช่วงเช้า (Asian Range: High/Low/Mid), เส้นแนวโน้ม EMA, RSI และความผันผวน ATR
2. **ออกแบบมาเพื่อ IQ Option Forex โดยเฉพาะ**:
   - คำนวณจุดเข้า (Entry), จุดทำกำไร (Take Profit), และจุดตัดขาดทุน (Stop Loss)
   - บอกค่าที่ต้องตั้งบนแถบสไลเดอร์ IQ Option ชัดเจน (เช่น ตั้ง Take Profit +17%, Stop Loss -14%)
3. **เหมาะสำหรับพอร์ตทุนน้อย**:
   - สามารถกรอกเงินทุนต่อไม้ (เช่น $2 หรือ $5) และเลือกตัวคูณ (x50, x100, x200)
   - ระบบจะแปลงค่ากำไร/ขาดทุนเป็น **เงินดอลลาร์จริง** ให้เห็นชัดเจน (เน้นกำไรทีละ $1 – $5 จบในวัน)
4. **แจ้งเตือนอัตโนมัติรอบบ่าย 3 (15:00 น.)**:
   - มีเสียงแจ้งเตือน (Chime) และเด้ง Browser Notification อัตโนมัติเมื่อถึงเวลา
   - มีปุ่ม **"⚡ วิเคราะห์ทันที"** ให้กดดูแผนการเทรดได้ตลอดเวลา
5. **กราฟ TradingView สดในตัว**:
   - สามารถเปิดดูกราฟแท่งเทียน 15 นาทีประกอบการตัดสินใจได้ในหน้าเดียว

## 📱 วิธีนำบทวิเคราะห์ไปตั้งค่าบน IQ Option

เมื่อถึงเวลา 15:00 น. หรือเมื่อกดปุ่ม **"วิเคราะห์ทันที"** คุณจะเห็นการ์ดสรุปแผน:
1. **ดูทิศทางสัญญาณ**:
   - 🟢 **BUY**: กดปุ่มสีเขียว (HIGHER) บน IQ Option
   - 🔴 **SELL**: กดปุ่มสีแดง (LOWER) บน IQ Option
   - ⏳ **WAIT**: ตลาดยังไม่เลือกทาง แนะนำให้รอดูแท่งเทียนถัดไป
2. **ดูการตั้งค่า Auto-Close**:
   - นำค่า **Take Profit %** (เช่น +17%) ไปใส่ในช่องตัดกำไรอัตโนมัติ
   - นำค่า **Stop Loss %** (เช่น -14%) ไปใส่ในช่องตัดขาดทุนอัตโนมัติ
3. เมื่อเข้าออเดอร์แล้ว ปล่อยให้ระบบตัดกำไรตามเป้า หรือหากได้กำไรตามพอใจแล้ว ($1-$3) สามารถกดปิดทำกำไรด้วยมือได้ทันที
